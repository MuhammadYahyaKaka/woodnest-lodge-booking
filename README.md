# WoodNest — Lodge Booking Website

A cinematic lodge booking landing page built from the Dribbble design
"Landing Page Design for Lodge Booking" by Nixtio:
https://dribbble.com/shots/27389159-Landing-Page-Design-for-Lodge-Booking

## Features
- Hero with live video background (cozy cabin in a snowy pine forest, Pexels free video by Mikhail Nilov), autoplay + loop
- Headline: Nature's Perfect Hideaways, rating 4.7 from 1,800+ stays
- Glass booking card: Evergreen Pine Family Lodge, $359/night, 2–5 guests, check-in after 2:00 PM, check-out until 12:00 PM
- 6 lodges with category filters
- Details button on every lodge opens a detail modal with photo, location, rating, guests/bedrooms/beds/bathrooms, description, amenities and what's included
- Reserve button opens a booking modal that calculates nights × price total and gives a booking reference
- Experiences, guest reviews, FAQ and Design Reference section with the original Dribbble shot images

## How to run
Open `index.html` in a browser — it is a single self-contained file (all images and the video are inlined). No server or build step needed.
